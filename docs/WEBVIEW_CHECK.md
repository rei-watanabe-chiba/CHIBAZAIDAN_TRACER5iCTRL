# WebView2 版を実機で確かめる手順(作り替えの 5 段目)

> 2026-11-20 にユーザーが確かめて問題が無かったので、Tk 版を消して WebView2 版に切り替えた。今の起動は `Traer5iAuto/start_measure_gui.vbs`(または `dist/Traer5iAuto/Traer5iAuto.exe`)。この手順は、画面を大きく変えたときの確かめにも使える。

Tk 版の画面のコードを消す前に、WebView2 版を本物の機器で使って確かめる。
**照射を伴う項目(B)は、ご自身で行う。**

## 起動のしかた

- `Traer5iAuto/start_measure_gui.vbs` をダブルクリックする。
- 2 つ同時には起動できない(開いていれば「すでに起動しています」)。
- 何かあればログのファイル `Traer5iAuto/config/app_log.txt` に残る。

## A. 照射なし

| # | すること | 見ること |
|---|---|---|
| A1 | 起動する | 本体画面の上の一覧に製造番号・IP。「確認中…」→「接続可」 |
| A2 | 「接続」 | 一覧が消えて本体画面が出る。状態の欄が「準備OK」か「ログイン待ち」 |
| A3 | ログイン画面なら PASS を入れて「ログイン」 | ログインして「準備OK」 |
| A4 | 本体画面のボタンをクリック(例: 設定を開いてキャンセル) | 機器が反応する。終わったら「↻ 画面更新」でメイン画面へ |
| A5 | 蓋を開ける / 閉じる | 開けると「蓋なし」「蓋とセンサーを確認してください」・ボタンは押せない。閉じると戻る |
| A6 | 計測ファイル・資料一覧・計測台帳を見る | Tk 版と同じ中身。資料一覧の「CSV選択」でファイルを選ぶ窓が出る |
| A7 | 最大化・解除・窓の端のドラッグ・段の境目のドラッグ | 古い画面・黒い所が出ない |

## B. 照射あり(ご自身で)

| # | すること | 見ること |
|---|---|---|
| B1 | 測定モード表を 1 行(例: Obsidian 10 秒)にして「▶ 自動計測」 | 確認のダイアログ。安全確認をチェックするまで「照射開始」は押せない |
| B2 | 照射開始 | 「☢ 照射中」の明滅・残り時間・「■ 停止」を押せる。終わると台帳に 1 行、`TracerData/pdz` に取り込み |
| B3 | 2 モード以上で自動計測 | 全部 ✓。「↻ 画面更新」でセットを閉じ、ID・subID が空になる |
| B4 | 照射中に「■ 停止」 | トリガーが離れ、台帳に「✕ 停止エラー」 |
| B5 | 照射中に蓋を開ける | すぐ止まり、台帳に「✕ 機器エラー」 |
| B6 | (できれば)照射中に USB を抜き、差し直す | 「照射停止」で待ち、同じ機器が戻ると自動でつなぎ直して「✕ 接続エラー」でセットを終える |
| B7 | (できれば)照射中に窓を閉じる | 「測定中です。照射を止めて終了しますか?」→ はい で照射が止まって閉じる |

## C. 別の PC(できれば)

- `dist/Traer5iAuto/` をフォルダごと持っていき、`Traer5iAuto.exe --selftest` を実行する。
  - 機器を探さずに起動を確かめ、`config/web_selftest.txt` に結果を書いて閉じる。
- 起動しなければ、WebView2 Runtime が入っているかを確かめる(Windows 11 は標準で入っている)。

## 確かめた後

- 問題が無ければ、Tk 版の画面のコードを消して WebView2 版を配布の形にする(VBS・exe・CLAUDE.md の書き直し)。
- このフォルダは git で管理していないので、消す前に `Traer5iAuto/` をフォルダごと控えておく。
